# Online E-Learning Platform with Integrated AI Chatbot

This is a full-stack web application for students to learn online and get help without leaving the platform. Students can create accounts, browse courses, enroll, follow the payment flow, watch lesson videos, and take quizzes. If they have a question or doubt, they can ask the chatbot directly on the site and receive a response there, without switching to Google or ChatGPT.

## Student features

- Sign up, sign in, and manage a student profile.
- Browse the course catalog and view course details.
- Enroll in courses and follow the payment flow.
- Watch lesson videos and take quizzes.
- Ask the integrated chatbot questions while using the platform.

## Admin features

- Manage courses and lectures.
- Manage student information.
- Track payment status.

## How the chatbot works

The chatbot is integrated with the learning platform to provide in-site question-and-answer support. The chatbot code is organized into Python components for the application, chat behavior, model, language-processing utilities, and training. Flask is used for the chatbot backend, with the OpenAI API identified as part of the integration.
The platform includes an integrated chatbot where learners can ask questions and get responses while studying. It provides in-platform support, so learners can get help without switching to Google or ChatGPT.
## Technology used

- **PHP** for the web application
- **MySQL** for storing platform data
- **HTML, CSS, JavaScript, and Bootstrap** for the interface
- **Python and Flask** for the chatbot backend
- **NLP utilities and model code** for chatbot processing

## Repository organization

The project includes separate folders for admin pages, student pages, PHP code, Python chatbot code, database files, templates, static resources, images, Bootstrap assets, JavaScript, and third-party dependencies.

Overall, the project brings course learning, quizzes, administration, payment-status tracking, and chatbot-based learner support together in one platform.
